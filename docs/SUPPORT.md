# SimRecipes support and moderation contact

Support and moderation concerns can be sent to
[support@simrecipes.app](mailto:support@simrecipes.app).

Include the affected recipe/profile URL, a short description of the concern,
and any relevant report ID. Do not send passwords, Apple identity tokens, or
other secrets.

Moderation reports are reviewed through the authenticated admin API. Reported
content can be hidden and abusive accounts can be suspended while the report
is resolved.

The moderation queue records report status and review timestamps so the team
can monitor response time and follow up on unresolved concerns.
